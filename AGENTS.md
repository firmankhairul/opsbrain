# OpsBrain - Agent Instructions

Managed-services ops workspace. Full rules: `ops-rules.md`.

1. For any task that names a customer or service, read the `ms-ops` skill first, then the customer's docs and knowledge base.
2. Never run a mutating action without explicit approval. Propose, wait, execute.
3. Track work as GitHub Issues following `docs/standards/ops-issue-format.md`.
4. Create MoP, MoM, report and KB documents only when asked or when an action item needs one.
5. No emoji in any report, issue or ticket.
6. Respond in the user's language. Keep technical terms in English.
